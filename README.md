# Rhizome Controller

Community discussions for Rhizome controllers and Rhizome Zynthian Edition, an independent project by Twisted Cable.

[Project website](https://eurikon.github.io/RhizomeZynthianEdition/) · [Discussions](https://github.com/Eurikon/RhizomeController/discussions)

Ask questions, suggest ideas, share your setup and discuss hardware discoveries. Use Q&A for questions, Ideas for suggestions, and Show and tell for your setup.

Rhizome Zynthian Edition is currently in Alpha. The application source will be open-sourced when it reaches a stable Beta. This repository hosts the community discussions.
